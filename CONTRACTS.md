# Internal implementation contracts

Application root is this directory. Research source paths resolve against its parent.
All offsets are Python Unicode `[start,end)`. All output paths stay under app root.

`config.load_config(path=None)` returns a dict with `_app_root` (Path), `_config_path` (Path), plus YAML values. `config.canonical_hash(value)`, `config.file_sha256(path)`, `config.write_json(path,value)`, `config.read_jsonl(path)`, `config.write_jsonl(path,rows)`, `config.corpus_hash(documents)` are shared helpers. `config.public_config(config)` excludes private keys. `PipelineError` is shared.

Clean document dictionary: `doc_id`, `source_sha256`, `text`, `text_sha256`, `pages` [{page_number,char_start,char_end,method}], `paragraphs` [{paragraph_id,char_start,char_end,indent_level}], `sentences` [{sentence_id,char_start,char_end,text}], `structures` [{structure_id,char_start,char_end,bab,pasal,ayat,butir}], `cleaning_rules`, `log`, `review_required` (list). Empty research documents fail. `segmentation.annotate_document(doc)` recomputes annotations against final text. `preprocess.prepare_corpus(config)` returns list of documents and writes data/clean only if all valid. `preprocess.load_clean_corpus(config)` checks saved provenance against current source/rules and returns sorted documents.

`tokenization.SourceTokenizer(hf_tokenizer)` exposes `count(text,prefix)`, `offsets(text)` (list of start/end tuples), `split_span(text,start,end,limit,prefix)` (contiguous span tuples, source slices). `tokenization.load_tokenizer(config)` loads pinned fast E5 tokenizer and returns SourceTokenizer. Tests use synthetic tokenizer fixtures, clearly identified, independent of downloads.

`chunking.semantic_units(doc,tokenizer,config)` returns [{unit_id,sentence_id,char_start,char_end,text}] (sentence gaps included to give full coverage). `chunking.semantic_breakpoints(units,unit_embeddings,percentile)` returns indices i with break after unit i. `chunking.build_chunks(doc,condition,tokenizer,config,unit_embeddings=None)` returns metadata rows; semantic embeddings supplied align with semantic_units. `chunking.validate_chunks(doc,chunks,condition,tokenizer,config)` raises PipelineError on invalid spans/coverage/tokens/metadata/overlap. Chunk fields follow the research specification, including source token coordinates for fixed chunks.

`embedding.E5Encoder(config,cache_dir=None)` exposes `.tokenizer` SourceTokenizer, `.embedding_config_hash`, `.resolved_config`, `.dependency_versions`; `encode_passages(texts)`, `encode_queries(texts)`, `encode_units(units)` return float32 normalized numpy matrices, unit cache shared C4/C5. No silent truncation. `embedding.embedding_identity(config)` returns resolved deterministic identity without loading model; same identity used to validate indices.

`indexing.build_index(condition,chunks,encoder,config,corpus_hash,output_dir)` writes index, mapping, manifest. `indexing.load_index(index_dir,config,corpus_hash=None)` returns object with `.index`, `.chunks`, `.manifest`, `.manifest_hash`. Validate all checksums/settings/current dependency identity. `retrieval.validate_bundle(indexes)` validates five conditions C1..C5 same identity. `retrieval.search_index(loaded_index,query_vector,k=10)` returns full result metadata with rank/score; sorts all FAISS rows (-score,row_id). `retrieval.load_queries(path,tokenizer,config)` validates research input. `retrieval.retrieve_batch(queries,indexes,encoder,output_path,top_k=10)` writes one row per qid/condition and returns rows. Batch requires >=top_k rows. Search allows smaller indices. One encode per unique query text.
